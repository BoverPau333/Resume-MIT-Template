# LaTeX CV & Motivation Letter Template

This repository contains the **LaTeX templates I use to generate my Curriculum Vitae and Motivation Letter**, specifically designed for **Computer Science and Software Engineering profiles**.

The goal of this template is to provide a **clean, compact and professional format** suitable for:

- Software engineering positions
- Artificial Intelligence and Machine Learning roles
- Research applications
- Master's and PhD applications in Computer Science

## Features

- Clean **engineering-oriented CV layout**
- Designed for **technical profiles (Computer Science / AI / Software Engineering)**
- Compact format inspired by **MIT-style resumes**
- Fully **customizable sections**
- Integrated **FontAwesome icons**
- Easy to adapt for different applications
- Compatible with **Overleaf and standard LaTeX distributions**

## Structure
├── cv.tex # Main CV template
├── motivation_letter.tex # Motivation letter template
├── personalPhoto.jpeg # Optional profile picture
└── README.md


## CV Sections

The CV template includes the following sections:

- Header with contact information
- Professional Experience
- Projects
- Education
- Technical Skills
- Languages

The structure is designed to highlight **technical achievements, research experience and engineering skills**.

## Motivation Letter

The motivation letter template is designed to be **highly parameterizable**, allowing easy customization for different universities or job applications.

It includes:

- configurable applicant information
- configurable university/program fields
- professional academic formatting

## Requirements

To compile the documents you will need:

- LaTeX distribution (TeX Live, MacTeX or MiKTeX)
- Or **Overleaf**

Main packages used:

- `fontawesome5`
- `enumitem`
- `hyperref`
- `graphicx`
- `tabularx`


or directly on **Overleaf**.

You can easily customize:

- personal information
- projects
- experience
- skills
- research interests
